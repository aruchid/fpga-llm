# FPGA 上的非线性算子

Softmax、LayerNorm/RMSNorm、RoPE、SiLU 这些运算都能放在 FPGA 上，计算量远小于矩阵乘法，难点在于用硬件近似 exp、除法、开方，以及精度控制。

## 各运算的硬件实现

| 运算 | 难点 | 常用实现 | 难度 |
|---|---|---|---|
| RoPE | sin/cos | 预算 sin/cos 表存 ROM，再做复数乘法 | 简单 |
| 残差相加、逐元素乘 | 无 | 加法器、乘法器 | 简单 |
| SiLU / GELU | sigmoid、tanh | 查找表（LUT）或分段线性近似 | 中 |
| RMSNorm | 平方和、1/√x | 累加平方和；1/√x 用 LUT + 1~2 次牛顿迭代；乘缩放系数 | 中 |
| LayerNorm | 多一步求均值 | 同上；两遍扫描，或 Welford 算法一遍完成 | 中 |
| Softmax | exp、除法、求最大值 | 见下 | 最难 |

Llama 系列用 RMSNorm（不减均值），比 LayerNorm 简单。

## Softmax 的硬件做法

1. **减最大值**：防止 exp 溢出，硬件实现必须做
2. **exp 改 2 的幂**：e^x = 2^(x·log₂e)，整数部分用移位，小数部分查小表，不需要指数运算单元
3. **除法变乘法**：整行只求一次 1/sum（LUT + 牛顿迭代），再逐个相乘
4. **Online Softmax**：扫描时同时更新最大值和累加和（FlashAttention 同样的技巧），少读一遍数据
5. **纯整数方案**：如 I-BERT 用多项式近似 exp，整个网络都用定点数

## 精度策略

- 矩阵乘法用 int8；非线性运算用更高精度（int32 定点或 fp16/bf16），并处理量化/反量化的缩放系数
- 参考模型准备两个版本：
  1. **浮点版**：评估量化和近似带来的误差（例如最终 token 是否一致）
  2. **硬件等价版**：numpy 完全按 FPGA 的定点算法实现（同样的表、同样的移位），使 RTL 仿真结果可以**逐比特比对**

## 为什么要放上 FPGA

- 以 stories15M（dim 288、6 层）为例，每层计算量很小；非线性运算若留在电脑上，**PCIe 往返延迟会占主导**
- 全部上 FPGA 后，电脑只发 token 编号、收下一个 token 或 logits，中间数据不出 FPGA
- 激活值放片上 BRAM；KV Cache 约 88 万元素（int8 约 0.9 MB），视芯片大小放 BRAM 或 DDR

## 整体结构：小型 NPU

- **矩阵单元**：32×32 GEMM / MVM
- **向量单元**（SFU）：Softmax、RMSNorm、RoPE、SiLU
- **控制器**：电脑一次性下发指令序列，FPGA 自行按序执行；换模型只换指令，不改硬件

## 分阶段迁移

1. 非线性运算全在电脑上，先跑通矩阵乘法 + PCIe
2. 搬上 RMSNorm、RoPE、SiLU、残差相加
3. 搬上 Softmax 和 KV Cache，注意力整体在 FPGA 上
4. 整个 token 推理在 FPGA 上，电脑只负责输入输出
