# L0 定点参考模型

FPGA 大模型推理项目的第一层：用 Python 写两个版本的 Llama 推理——浮点版作标准答案，硬件等价版用纯整数实现，作为 RTL 逐比特比对的"硬件契约"。

代码在 `l0/`，项目总体设计见 [FPGA 矩阵运算通讯全流程](01-总体设计.md)。

## 两个版本

| 版本 | 作用 |
|---|---|
| 浮点版（`ref_float.py`） | 逐行复刻 llama2.c 的 `run.c`，float32 |
| 硬件等价版（`ref_hw.py` + `fixedpoint.py`） | 全部整数运算，算法与将来的 RTL 一模一样，RTL 输出必须与它逐比特一致 |

## 数值格式

- **激活值 / 残差流**：Q16.16 定点数（32 位有符号，低 16 位是小数）
- **权重**：int8 对称量化，每个输出行一个缩放系数 SW（存成 Q24 整数）
- **送进矩阵单元的激活值**：int8 + 一个 2 的幂移位量 s。s 由向量最大值的位宽决定（硬件里就是前导零计数），**不需要除法**。代价：最大值被映射到 64~127，最多损失 1 位精度
- **矩阵乘**：int8 × int8 → int32 累加 → × SW → 移位回 Q16。分块累加是精确的整数加法，所以**结果与 32×32 怎么分块无关**
- **舍入**：统一"加半个 LSB 后算术右移"
- **KV Cache**：int8，每个位置、每个 KV 头一个移位量

## 非线性运算的实现

具体原理见 [FPGA 上的非线性算子](02-非线性算子原理.md)，这里记录实际选定的参数：

| 运算 | 实现 | 测得误差 |
|---|---|---|
| 1/√x | 192 项查找表 + 2 次牛顿迭代 | 相对误差 < 2e-4 |
| 1/x | 256 项查找表 + 2 次牛顿迭代 | 相对误差 < 1e-4 |
| exp | 转成 2 的幂：整数部分移位，小数部分 257 项表 + 线性插值 | 绝对误差 < 5e-5 |
| Softmax | 减最大值 → 2 的幂 → 求和 → 一次 1/x → 逐个相乘 | 概率误差 < 2e-4 |
| sigmoid / SiLU | [-16, 16) 512 段表 + 线性插值，范围外饱和 | SiLU 误差 < 2e-3 |
| RMSNorm | 平方和在 Q8 下累加；除以 n 用常数倒数乘法；1/√x 同上 | 相对误差 < 2% |
| RoPE | cos/sin 表 Q2.14 | 误差 < 1e-3 |

经验：sigmoid 的查找表起初只覆盖 [-8, 8)，x 较大时 SiLU = x·sigmoid(x) 会把表末端的误差放大（x=12 时误差 0.004），把范围扩到 [-16, 16) 后解决。

## 验证结果（随机权重的小模型）

- 硬件等价版与浮点版生成的 token 序列完全一致
- 逐位置对比 logits：余弦相似度最低 0.999，top-1 一致率 100%
- 位宽需求（含符号位）：矩阵乘累加 17~18 位；累加值 × SW 需要 32~34 位；残差流 20 位；Softmax 求和 22 位；注意力 P·V 累加 35 位

## 验证结果（真实模型 stories15M，2026-11-15）

提示词 "Once upon a time"，贪心解码 64 个 token：

- 浮点版输出连贯的英文故事，说明权重读取、分词器、RoPE 等与 llama2.c 一致
- 硬件等价版前 44 个 token 与浮点版完全相同，第 45 个 token 起分叉，之后仍是通顺的故事。int8 量化下贪心解码迟早分叉，属正常现象，所以**逐 token 比对要用教师强制**
- 教师强制逐位置对比（64 个位置）：top-1 一致率 96.9%，logits 余弦相似度平均 0.9991、最低 0.980，最大绝对误差 1.54
- 速度（Mac numpy）：浮点版约 760 tok/s，硬件等价版约 96 tok/s

真实模型的位宽需求（有符号，含符号位），RTL 按此设计：

| 位置 | 位宽 |
|---|---|
| 矩阵乘 int8×int8 累加（288 或 768 项） | 18~19 |
| 累加值 × SW | 32~34 |
| 矩阵乘输出 / 残差流（Q16） | 19~22 |
| 注意力 q·k 点积 | 18 |
| 注意力 P·V 累加 | 35 |
| RMSNorm 平方和 | 26 |
| RMSNorm 输出、1/√x | 23~24 |
| Softmax 求和 | 22 |
| SwiGLU 输出 | 22 |

结论：矩阵单元的累加器 24 位绰绰有余；"× SW" 和 P·V 这两处需要 36 位左右的乘法器 / 累加器；其余数据通路 32 位（Q16.16）不会溢出。
